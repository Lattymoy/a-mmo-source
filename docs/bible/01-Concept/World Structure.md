# World Structure

**Status:** `STATED`

## The hub

Humanity gathers within a hub. The shared world begins there.

Stated contents:

- a training spot
- vendors
- quests
- *etc* — the list was open-ended, not exhaustive

## Missions

You take on missions to travel to **procedural zone-based areas**.

Missions are run **solo or matchmade**.

## Consequence for co-op

**Status:** `PROPOSED` — reading of the above, not stated

This is hub-and-instance, not a persistent shared field. Matchmade missions mean
a **small, bounded party** on a known clock, not arbitrary players wandering into
each other.

That is a materially easier problem than the one [[Tick Scheduler]] was built
for, and it makes the scheduler more viable, not less: a fixed party in an
instance can run lockstep-with-skip cleanly.

It also means the desktop MMO lineage in [[Prior Art]] is no longer the closest
comparison. The nearest structural relatives are hub-and-instance boss hunts.

**Open:** the repo is named `a-mmo-source`. What is described here is not an MMO
in the persistent-world sense. Name is Mac's call; recorded here only so the
mismatch is not mistaken for a design decision.
